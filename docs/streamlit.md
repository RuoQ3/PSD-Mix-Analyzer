# Streamlit 操作界面

安装依赖后，从仓库根目录启动：

```bash
python -m pip install -e '.[ui]' -c requirements.lock
python -m streamlit run src/psd_analyzer/ui/streamlit_app/app.py
```

这是本地分析工具。q 是颗粒级配描述指标，不代表产品性能；Target q 是参考目标，
不是控制限。图表和指标描述偏离，不作产品质量合格判定。

## 页面与工作流

首页提供模板下载和 Excel 导入。模板包含 Materials、Measurements、PSD、Recipe，
示例配方为草稿。导入由 Application 调用输入适配器完成，UI 不解析 Excel；
错误信息保留文件、sheet、行号、列名、原始值和原因。导入失败保留上次成功的数据，
并继续显示当前数据文件名；应修复数据后重新导入。

- **生产监控**：只允许选择具有外部批准引用的 released 配方。正式配方比例只读。
  逐行选择原料批次和测量版本，设置粒径范围后执行分析。
- **原料替代**：显式选择要替代的配方行和候选测量；原始比例保持不变。
  展示原始与候选 PSD、差值、q、关键粒径和误差。这是风险分析，不是正式配方变更。
- **研发模拟**：唯一可编辑比例的页面。表格中只能编辑模拟比例，Application 校验
  非负且总和为 100%（使用 domain 浮点容差）；非法输入会禁用执行按钮，不自动归一化。
  所有结果和历史类型均标记为研发模拟。
- **历史分析**：按配方 ID、批号、分析类型、UTC 日期区间筛选摘要；选择记录才加载完整
  配方版本、批次、配置和 PSD。支持 q 趋势、显式指定生产基准和历史比较。
  比较要求兼容的配置、网格和测量协议；不兼容会给出明确原因，不暗中重算历史快照。

参数区默认只显示 D_min、D_max 和可选 Target q；q bounds、插值方法与关键粒径在高级
设置中。关键粒径使用逗号分隔，按用户配置动态展示。范围外混合 PSD 使用恒定端点延伸。
目标曲线遵循 Modified Andreasen 自身的 0/1 边界。

## 保存、基准与状态

执行分析不会自动写数据库；查看结果后点击“保存分析”。同一份结果保留同一个 UUID，
重试或双击不会创建重复记录。更改输入会隐藏旧结果并提示重新分析。

历史页可显式将生产记录设为同一配方 ID + 版本的基准；切换会替换该版本的旧基准。
生产页面在配置兼容时展示基准 PSD 和差值，否则保留当前分析并说明不能比较的原因。
草稿和模拟结果不会成为生产基准。

session_state 仅保存已导入工作簿、当前结果、保存状态和临时输入。
不保存数据库 Session、Engine 或 repository。composition.py 负责连接 Application 与
基础设施；页面只使用 Application 和 Visualization。数据库设置见 [persistence.md](persistence.md)。
历史数据是分析记录，不是正式产品质量判定数据库。
